# Site — Dr. Carlucci Martins

Landing page do Dr. Carlucci Martins, ortopedista especialista em mão e pé.

## Deploy

Site estático (HTML/CSS/JS puro, sem build). Basta importar este repositório no [Vercel](https://vercel.com/new) — nenhuma configuração adicional é necessária.

## Pendências antes de publicar oficialmente

- Substituir placeholders `[ ]` (CRM, RQE, telefone, e-mail, endereço, horários)
- Inserir fotos reais do Dr. Carlucci nos espaços marcados
- Adicionar embed do Google Maps no rodapé
- Substituir depoimentos de exemplo por avaliações reais
